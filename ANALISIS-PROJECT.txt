================================================================================
12. ARCHITECTURE PROBLEMS
================================================================================

1. DUAL CSS FRAMEWORK OVERLOAD
   Bootstrap 5 + Tailwind CSS v4 are both loaded. Tailwind is used for only
   ~5 utility classes. Adds unnecessary complexity and potential style conflicts.

2. DUAL SMOOTH-SCROLL SYSTEMS CONFLICT
   Two independent Lenis instances created - one in MainPortfolio.tsx (wired to
   GSAP ScrollTrigger) and one in UseNav.ts (for scrollTo navigation). Both
   have separate RAF loops causing:
   - Competing scroll position management
   - Double RAF processing
   - Potential scroll jank

3. HOOKS DIRECTORY MISNAMED AS "functions/"
   The functions/ directory contains React hooks but doesn't follow React naming
   conventions (use prefix lowercase) or standard project structure (hooks/).

4. ALL PAGES ARE CLIENT-RENDERED
   Every page/component is "use client". No server components, no static
   generation, no SSR benefits. The entire app hydrates client-side.

5. CSS ANIMATION EXPLOSION
   ~4,200 lines of animation CSS across 9 files, many running infinitely even
   when sections are not visible (though CSS animation-play-state is used
   in some cases).

6. NO ERROR BOUNDARIES
   No React error boundaries anywhere. A crash in any canvas or animation
   would crash the entire app.

7. UNUSED HEAVY DEPENDENCIES
   Three.js ecosystem (~1MB+ bundle) is installed but never used.
   @gsap/react is also unused.

14. IMPORTANT FINDINGS
================================================================================

1. GRAVITYWELL HAS A MEMORY LEAK
   RAF loop is never cancelled on unmount. The animate() function keeps calling
   itself via requestAnimationFrame but the cleanup only removes event
   listeners.

2. THREE.JS ECOSYSTEM (~1MB+) IS COMPLETELY UNUSED
   This is the single largest unnecessary bundle contributor.

3. TWO LENIS INSTANCES CONFLICT
   MainPortfolio.tsx creates one with GSAP integration; UseNav.ts creates a
   separate one. Both run RAF loops simultaneously.

4. POPPINS FONT IS DECLARED BUT NEVER LOADED
   body { font-family: "Poppins" } falls back to system font.

5. 4 OUT OF 5 PROJECTS ARE UNREACHABLE
   All share slug "flower-shop-website", so only the first project can be
   accessed via /projects/flower-shop-website.

6. @GSAP/REACT IS UNUSED
   Installed but never imported anywhere.

7. ALL 5 ORBITICON COMPONENTS RUN CONCURRENT RAF LOOPS
   When HomeSection is visible: 5 x 30fps = 150 RAF callbacks/second.

8. SPLASH SCREEN RUNS 3 SIMULTANEOUS CANVAS ANIMATIONS
   UseParticle + GravityWell + orbit effects all running at once.

9. PROJECT DETAIL PAGE IGNORES THEME
   Uses hardcoded bg-dark classes regardless of dark/light mode.

10. NO SEO/ROUTING INFRASTRUCTURE
    No sitemap, no robots.txt, no metadata beyond title, all client-rendered.
